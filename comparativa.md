# 1.Licencias y Modelos
## 1.1 Software libre (FSF)
Un software libre es un software que respeta la libredtades de los usuarios asi como tambien la comunidad. Es decir que los usuarios tienen la libertad de modificar y ejecutar el software. 

Por eso cuando hablamos de software libre no nos referiamos a libretad, no a que el software es gratis. Al final un software libre le da al usuario libertad de hacer lo que queramos. Este confuncion viene de que en ingles free (libre) tambien se utiliza para referirse a algo gratis. 

Al finall un softher libre tiene que seguir una serie de criterios para que un programa sea considerado libre. Estos criterios son las cuatro libertades esenciales:

- **Libertad 0:** Libertad de ejecutar el programa para cualquier propósito y como desee el usuario.
- **Libertad 1:** Libretad de poder estudiar como funciona el programa y poder cambiarlo para que haga lo que desee. Es impriscindible poder tener acceso al codigo fuente.
- **Libertad 2:** Libertad para poder redistribuir para ayudar a otros.
- **Libertad 3:** Libertad para una vez modificadas seamos capazes de distribuirlas a otros. Asi la comunidad es capaz de de beneficiarse de las modificaciones realizadas. El codigo fuente sigue siendo un requisito.

En conclusion cuando hablamos de software libre estamos nos referimos a un software que el usuario goza de la libertad de ejecutar, copiar, distrubuir, estudiar, modificar y mejorar el software.

## 1.2 Código abierto (OSI)
Un código abierto es un modelo de software en el que el codigo fuente esta disponible. Sin embargo que tengamos acceso al código no significa que sea un código abierto para eso tambien tenemos que cumplir con los siguientes criterios:

**1. Redistribución libre:** La licencia no puede impdir que el software se venda o se distribuya, aunque este forme parte de un paquetes junto con otros programas y no requirirá regalías no otro cargo por ellas.
**2. Código Fuente:** El programa tiene que incluir un codigo fuente pero este se debe porder distribirse en código fuente y en forma copilada. Pero claro si el producto no incluye el codigo fuente este tiene que poder obetener por otro medio el cual tiene que estar bien publicitado y con un coste razonable, siempre se peferirá que se pueda descargar por internet sin coste adicional. Esta prohibido que el código fuente intencionadamente este ofuscado y que no se permitan formas intermedias como la salida de un preprosador o traductor.
**3. Obras Derivadas:** La licencia tiene que dejar la modificacion, otras obreas derivadas y la distribucion de las mismas bajo los terminos de la licencia original.
**4. Integridad del código fuente del Autor:** Los usuarios pueden modificar el texto por estas modificaciones tienen que estar separados del codigo original y estos se aplicaran a en la copilación estos se llamaran parches y estos son los que se pueden distribuir en vez de el codigo fuente modificado. Tambien el Autor puede exigir que la versión modificada tenga otro nombre para que se diferencie del programa original.
**5. No discriminación contra personas o grupos:** La licencia no puede discriminar a ninguna persona o grupo.
**6. No discriminar en los campos de actividad:** La licencia no se puede limitar en que se utiliza el programa ni en campo se pueda utilizar.
**7. Distribución de la Licencia:** La liciencia debe poder mantenerse despues de la distribucion a otras personas aunque no se haya firmado la licencia adicional.
**8. La licencia no debe ser específica para un producto:** La licencia dep program debe siguir sirviendo independiente de los programas con los que se distribuya.
**9. La licencia no debe restringir otro software:** Una licencia que ha decidido ser de codigo abierto no puede obligas a otros programas a ser de codigo abierto aunque se distribuyan juntos.
**10. La licencia debe ser neutral tecnológicamente:** La licencia no puede depender de una tecnoligia concreta. POr lo que la licencia debe mantenerse independiente de la tecnología o interfaz.

## 1.3 Software propietario
Este tipo de software es el que el titular mantiene el control sobre las condiciones de uso. En este software no se pueden garantizar las cutro libretades explicadas anteiormente porque estas liciencias pueden establecer restricciones sobre el uso, modificacion y distribucion.

Es por esto que tambien no se consideran codigos abiertos porque al poner estas condiciones entran en confilto con algunas de los criterios establecidos. 

Estos software tambien estan protegido por los derechos de autor, es lo que permite que el autor establezca las condiciones bajo las que se puede utilizar o distribuir sus programas.

## 1.4 copyleft
El copyleft sson mecanismos arientados para las licencias de software libre para garantizar que las libretades software continuen una vez este se haya redistribuido sus versiones modificadas.

Se utiliza principalmente para evitar que alguien se aprobeche de un software libre al utilizarlo modificarlo y luego elimine esa libretades. Aunque es un buen mequenismo para las licencias no significa que todos los software utilicen copyleft.

## 1.5 AGPL
La AGPL es una licencia de software libre que tambien utiliza copyleft, esta licencia esta diseñada especialmente para programas que dunciones en servidores y que los usuarios utilizan a través de un red.

En una GPL trdicional los usuarios pueden coger el programa, modificarlo, poner la version modificada en su servidor y otros usuarios pueden utilizarlo desde una paguina web pero no estos usuarios no estan realmente recibiendo una copia del programa.

Mientras que con AGPL tiene una condicion de que si un usuario modifica el codigo se establece que los usuarios pueden obtener el código fuente de la version modificada.

## 1.6 Community vs Enterprise
Cuando hablamos de Community y Enterpriese son dos versiones de un mismo programa pero que ofrecen direntes servicios.

- **Community:** Esta version esta orientada a la comunidad y puede ofrecer normalmente las funciones principales del programa. En algunos tambien cuentan con licencias de software libreo o codigo abierto, dejando que los usuarios puedan utilizarlos a su gusto. 

- **Enterprise:** En esta version principalmente esta pensada para empresas por lo que pueden tener funciones adicionales que no estan pensados para Community como lo serioa sercios de soportes, mantenimiento o financias y sus condiciones de licenci pueden ser diferentes. 

Las diferenceas no solo estan en los enfoque y en el precio si no en las necesidades de su publico objetivo por lo que sus funciones pueden ser muy diferentes.
